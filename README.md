## Projetos acadêmicos

### Modelagem de Dados — Lavanderia Sta. Bárbara

Projeto acadêmico desenvolvido em grupo durante minha formação em Ciência da Computação.

O trabalho consiste na modelagem de um banco de dados para uma lavanderia real, contemplando:

- Levantamento de requisitos
- Identificação de entidades e atributos
- Desenvolvimento do Diagrama Entidade-Relacionamento (DER)
- Elaboração do modelo lógico
- Definição de relacionamentos entre tabelas
- Normalização de dados

**[Acessar o projeto completo no GitHub](https://github.com/VeronicaPimentel/modelagem-de-dados-lavanderia)**
